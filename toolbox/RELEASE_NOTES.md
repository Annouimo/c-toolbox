模块化迁移预览版。仅下载 c_toolbox_v0.6.0.py，使用 Python 3.9+ 离线运行。

- 创建目录时选择输入骨架；默认 main.c 仅引入基础 IO。
- 类型读写随对应头文件提供；向量按元素类型引入，自定义容器显式声明。
- 新增数学、位操作、BigInt、矩阵、日期、数组与前缀和等模块。
- 每题固定依赖版本；prepare.py 展开源码、编译检查并复制，保留原文件。
- 接口存在不兼容调整，旧项目保留其原有头文件与 prepare.py。

此工作流仅创建草稿，核对跨平台检查及附件后人工发布。源码许可 MIT-0，工程 MIT，手册 CC BY 4.0，详见 LICENSING.md。
