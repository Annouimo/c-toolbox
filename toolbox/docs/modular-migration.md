# 模块化迁移约定

本文件记录已确认的目标。逐项实现去向见 [旧组件处理结果](legacy-mapping.md)，平台验证以当前提交 CI 为准。

## 接口

- 取消 c_toolbox.h 总入口；main.c 默认只包含 ctb_io.h。
- 基础 IO 不依赖 String 或实例化 Vector；类型读写随类型头文件提供。
- 常用 Vector 按元素类型分头文件；自定义类型通过生成器声明。
- 计算结果优先返回；多结果返回结构体；检查接口返回状态与值。
- read_int() 等直接返回值，失败报告错误并退出；try_read_int() 返回状态与值，允许处理 EOF。
- 创建、复制、切片返回拥有资源的新对象；原地修改和释放传入指针。文档明确释放责任与浅拷贝限制。
- 普通读取跳过空白；专门 raw 接口保留空格、空行。

## 旧组件处理

| 分类 | 保留或整合 | 删除 |
|---|---|---|
| 整数与数位 | 进制与数位、GCD/LCM、试除判素数、素数筛 | 重复的专用进制实现 |
| 位运算 | 设置、清除、翻转、读取位；二进制显示并入进制转换 | 无 |
| 数学 | 普通阶乘、整数幂、浮点比较、四舍五入、固定小数输出、多项式、二分求根、复数 | 二次方程组件、计算器交互 |
| 大整数 | 统一 BigInt 加减乘除、小整数除法与阶乘 | 分立存储实现 |
| 数组 | 统计、整数频次、最长相等段、最大子段和、差分、前缀和、矩阵 | ST/RMQ、最长逐项加一段 |
| 排序查找 | 排序、查找、边界、自定义比较、argsort、去重、离散化、整数答案二分 | 教学排序、特定排名规则 |
| 字符串 | 合入 String/StringList，保留最长连续指定字符 | 重复字符数组实现 |
| 日期时间 | 日期合法性、闰年、比较、日期差、天数推移、时刻与时长 | 时区等扩展 |
| 枚举搜索 | 下一排列、组合迭代、Vector 栈 | 记忆化、括号匹配、网格 DFS/路径专用模板 |

## 创建与发布

- 单文件 Python 离线发布，生成模块头文件、main.c、prepare.py、Markdown 手册。
- 创建目录时选择空 main、T 组、EOF、哨兵、q 次操作骨架；骨架使用新 IO 并按需增加包含。
- 已有目录警告且不覆盖，不自动提交准备。
- prepare.py 仅展开本地依赖、编译检查、复制结果；不做 AST 分析或函数裁剪。
- 每题固定创建时版本；更新入口不修改旧题。
- 大多数示例直接删除，README 只留少数用法示例。
- 版本延续 0.x；发布草稿验证后发布单个版本化 Python 附件，不原地替换附件。
- 原脚手架源码及发布流程从新仓库当前树移除，但提交历史保留；旧仓库不删除历史。

## 验收

- 基础 IO 单独包含后无 String/Vector 定义。
- 每个公共头文件可独立编译，组合包含无重复定义。
- 测试 EOF、格式错误、越界、空白行、raw、跨行切换和资源所有权。
- 测试各输入骨架、目录保护、递归展开、离线单脚本和编译失败不复制。
- GCC、Clang、Windows MinGW 检查通过。
